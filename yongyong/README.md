# 🐉 용용이 — 음성 업무 비서

"용용아" 하고 부르면 Studio Display 마이크로 듣고, Claude Code(Claude Pro 로그인)로 생각해서, 화면 속 아기 용 캐릭터가 입을 움직이며 대답합니다.

## 설치 (맥미니 터미널에서 한 줄, 업데이트할 때도 같은 명령)

```bash
curl -fsSL https://raw.githubusercontent.com/dreamer9761/dreamer9761/claude/mac-mini-local-setup-du34lc/yongyong/bootstrap.sh | bash
```

AI(Claude Code), 음성인식(Whisper), 캐릭터까지 한 번에 설치하고 바탕화면에 **용용이** 아이콘을 만듭니다.

설치 스크립트가 맥 사양(칩, 메모리, 마이크)을 읽어서 말로 알려 주고, 메모리에 맞는 음성인식 모델을 골라 설치합니다.

## Claude 로그인 (처음 한 번)

용용이를 켰을 때 Claude 계정이 연결돼 있지 않으면 캐릭터 창에 **로그인 화면**이 나옵니다.
1. **로그인 시작** → 터미널과 브라우저가 열림 → Claude 계정으로 로그인 후 **Authorize**
2. 터미널에 나온 `sk-ant-oat01-…` 토큰을 복사해서 캐릭터 창 칸에 붙여넣고 **연결하기**

터미널로 하고 싶으면 `~/dreamer9761/yongyong/login.sh` 도 같은 일을 합니다.

브라우저에서 Claude Pro 계정으로 승인 → 터미널에 나온 `sk-ant-oat01-…` 토큰을 붙여넣으면 `yongyong/.env` 에 저장됩니다(이 맥에만 저장, git 에 안 올라감).
용용이가 "Not logged in" 또는 "로그인이 필요해요" 라고 하면 이걸 다시 실행하세요.

## 실행

바탕화면의 **용용이** 아이콘을 더블클릭 (또는 `~/dreamer9761/yongyong/run.sh`).
용용이 캐릭터 창이 뜨고 "용용이 준비됐어요" 하고 인사합니다.

| 캐릭터 모습 | 뜻 |
|---|---|
| 둥실둥실, 눈 깜빡 | 대기 중 ("용용아" 기다림) |
| 초록 빛 고리가 퍼짐 | 듣고 있어요 |
| 말풍선 ··· | 생각(작업) 중 |
| 입이 소리에 맞춰 움직임 + 자막 | 말하는 중 |

- 처음 실행할 때 마이크 권한 창이 뜨면 **허용**
- 음성인식 모델 다운로드 때문에 첫 실행은 몇 분 걸려요
- 종료: `Control` + `C`

## 말하는 법

| 이렇게 말하면 | 용용이가 |
|---|---|
| "용용아" | "네" 하고 8초 동안 다음 말을 기다림 |
| "용용아, ○○ 해 줘" | 바로 처리하고 대답 |
| 대답 후 8초 안에 이어서 말하기 | "용용아" 없이도 알아들음 |
| "용용아, 새 대화" | 이전 대화를 잊고 처음부터 |

개발 작업은 `~/projects` 폴더에서 합니다. 고객에게 보내기·삭제·결제처럼 되돌리기 어려운 일은 먼저 물어보도록 `persona.md` 에 적어 뒀어요.

## 크몽 상담창 연결 (사파리)

용용이는 사파리에 띄워 둔 크몽 탭의 글자를 **읽기만** 합니다 (클릭·메시지 전송 안 함).

**처음 한 번 설정**
1. 사파리 → `설정…` (`⌘` + `,`) → **고급** → 맨 아래 "**웹 개발자를 위한 기능 보기**" 체크
2. 사파리 → `설정…` → **개발자** 탭 → "**Apple Events의 JavaScript 허용**" 체크
   (예전 사파리: 메뉴 막대 **개발자용** → "Apple Events의 JavaScript 허용")
3. 테스트: `~/dreamer9761/yongyong/run.sh --kmong`
   → "터미널이 Safari를 제어하려고 합니다" 창이 뜨면 **허용** → 지금 화면을 요약해서 읽어 줌

**사용**
- 용용이가 켜져 있으면 30초마다 크몽 탭을 확인하고, 새 문의가 오면 먼저 "크몽 알림이에요…" 하고 말해 줍니다.
- "용용아, 크몽 확인해 줘" / "용용아, 지금 크몽 손님 누구야?" 하고 물어봐도 돼요.
- 주문자별 기록(연관 계정, 이전 주문, 진행 상황)은 `yongyong/data/customers.md` 에 쌓여서, 다음에 같은 손님이 오면 예전 기록까지 함께 알려 줍니다.

## 음성 / 텍스트 선택

캐릭터 창 아래 버튼으로 고릅니다 (마지막 선택을 기억).
- **🎤 음성**: "용용아" 하고 불러서 말로 대화
- **⌨️ 텍스트**: 마이크를 끄고 아래 칸에 글자로 입력 (Enter 로 보내기), 대화 내용이 말풍선으로 쌓임
- **🔊 / 🔇**: 대답을 소리로도 들을지 (끄면 화면 글자로만)
- 말로 "용용아, 텍스트 모드로 바꿔" / 글로 "음성 모드" 라고 해도 바뀝니다.

## 크몽 현황 · 아침 브리핑

- "용용아, 크몽 현황 알려 줘" → 사파리에 로그인된 크몽의 주문·수익·메시지 페이지를 새 탭으로 열어 **읽기만** 하고 닫은 뒤,
  신규 결제 / 발송 안 한 주문 / 최근 문의 / 이번 주·이번 달 매출을 말로 요약하고 화면에 보고서를 띄웁니다.
  처음에는 크몽 메뉴에서 페이지 주소를 찾느라 몇 분 걸릴 수 있고, 찾은 주소는 `data/memo.md` 에 기억합니다.
- "용용아, 9월 매출 얼마야?" → 주문 목록을 다음 페이지로 넘기며 그 달 결제를 모두 더해 알려 줍니다. 끝난 달 결과는 `data/sales.md` 에 저장해 다음엔 바로 답합니다.
- 매일 아침 9시에는 부르지 않아도 날씨 → 뉴스 → 크몽 현황을 브리핑합니다 (`YONGYONG_BRIEFING_TIME`).

## 음악 (지니뮤직)

"용용아, 아이유 좋은날 틀어 줘" → 사파리에 로그인된 지니 웹에서 검색해 첫 곡의 듣기 버튼을 눌러 줍니다.
"음악 꺼 줘", "소리 30으로" 도 됩니다. 처음 한 번: 사파리 설정 → 웹 사이트 → 팝업 윈도우 → genie.co.kr **허용**.

## 첨부 파일

대화창의 📎 버튼(맥에서는 끌어다 놓기도 가능)으로 사진·PDF·문서·엑셀을 붙여 보내면 용용이가 열어 보고 대답합니다.
휴대폰 사진은 자동으로 줄여서 올라가고, 파일은 맥미니 `data/uploads/` 에 저장됩니다.

## 메일 발송 알림 (허브 → 크몽)

30분마다(오전 9시~오후 9시) 허브 '메일 색인'에서 우리가 고객에게 새로 보낸 메일을 찾으면, 그 고객의 크몽 대화창에 남길
"이메일로 보내드렸습니다" 알림을 화면에 준비하고 알려 줍니다. [크몽 대화창에 넣기] → 해당 고객 대화를 열고 입력창에 넣음 → 크몽에서 직접 전송.
알림 문구는 `data/mail_notice.txt` 로 바꿀 수 있습니다 ({닉네임}, {제목} 자리 표시). "용용아, 메일 발송 알림 보여 줘" 로 다시 열기.

## 계정복구 증빙자료 (네이버 MYBOX)

맥용 네이버 MYBOX 앱으로 증빙자료 폴더를 맥미니에 동기화한 뒤 "용용아, 증빙 폴더 설정해 줘" → 폴더 선택.
(홈 폴더의 MYBOX 동기화 폴더는 자동으로 찾습니다.) 상담 초안·블로그를 쓸 때 관련 증빙을 찾아 읽고 근거로 씁니다. 읽기만 하고, 다른 고객 개인정보는 넣지 않습니다.

## 증빙 색인 (복구 사례 찾기)

"용용아, ○○ 폴더 색인 만들어 줘" (예: 계정복구 캡처를 모아 둔 폴더) → 폴더 안의 캡처·문서·하위 폴더를 8개씩 열어
플랫폼·사유·결과(복구됨 등)·날짜·요약 표(`data/evidence_index.md`)를 만듭니다. 새로 생긴 것만 추가로 정리합니다.
이후 "개인정보 위반 복구 사례 알려 줘" 같은 질문은 이 표와 스포트라이트 내용 검색(mdfind)으로 바로 찾습니다.

## 이메일 기록 색인 (네이버 메일 백업 · NAS)

1. 네이버 메일에서 메일함을 내려받아(.eml) 폴더에 저장, NAS 는 Finder 에서 연결(⌘K → smb://NAS주소)
2. "용용아, 메일 백업 폴더 추가해 줘" → 폴더 선택 (여러 개 가능)
3. "용용아, 메일 색인 만들어 줘" → .eml/.mbox/.emlx 를 읽어 `data/mail.db` 검색 색인 (맥미니 안에서만, 새·바뀐 파일만, 중복 메일 1통으로)
- 매일 새벽 3시 10분에 새 메일만 자동 추가. 상담·사례 찾기에서 "블루키워즈 메일 찾아 줘" 처럼 바로 검색합니다.

## 크몽 상담 (답변 초안)

사파리에서 상담할 크몽 대화를 열고 "용용아, 이 손님 상담해 줘" → 대화를 처음부터 다 읽고, 고객 분류·허브 정보·크몽 '자주 쓰는 문구'를 참고해
**상담 필요 내역**(받은 것 ✅ / 더 필요한 것 ❓)과 **답변 초안**을 화면에 띄웁니다. 초안을 고친 뒤 [크몽 입력창에 넣기] → 크몽에서 직접 보내기.
용용이는 메시지를 직접 보내지 않습니다. 자주 쓰는 문구는 캐릭터 창 오른쪽 아래 [자주 쓰는 문구]에 "### 제목" + 내용으로 붙여넣어 저장합니다 (`data/kmong_templates.md`).

## 주간 블로그 초안 (네이버 · 티스토리)

매주 월요일 10시(또는 "용용아, 블로그 글 써 줘")에 용용이가 이번 주 글을 씁니다. 주제는 번갈아 ① 크몽 실제 리뷰 소개 ② 온라인 셀러 소명 노하우.
네이버용·티스토리용 제목/태그/본문을 각각 화면에 띄우면 [글쓰기 화면 열기] → [제목·본문·태그 복사] → 붙여넣고 **직접 발행**합니다.
초안은 `data/blog/날짜.md` 에 남습니다. 리뷰는 지어내지 않고 실제 리뷰만, 고객 닉네임은 가립니다.

## 음악: 지니 / 유튜브 선택

- "용용아, 유튜브에서 유키 구라모토 조회수 높은 것 틀어 줘" → 유튜브를 조회수 순으로 검색해 위에서 10개를 하나의 재생목록으로 이어서 재생
- "지니로 아이유 틀어 줘" → 지니. 아무 말도 없으면 기본 서비스로 ("앞으로 음악은 유튜브로 해 줘" 로 바꾸기)
- 처음 한 번: 유튜브 창에서 Safari → 이 웹 사이트에 대한 설정 → 자동 재생 → 모든 미디어 자동 재생 허용

## 기상 음악

매일 아침 7시에 지니에서 걸그룹 노래(매일 다른 곡)를 작은 소리로 틀고 1분 30초에 걸쳐 키웁니다.
"용용아, 알람 6시 반으로 바꿔 줘" / "기상 음악 꺼 줘" 로 바꿀 수 있고, 설정은 `data/settings.json` 에 기억합니다.

## 대기 화면

맥을 10분 동안 아무도 쓰지 않으면(다른 앱 작업 포함, 용용이가 일하는 중엔 제외) 캐릭터 창(사파리)이 화면 가득 커지면서 큰 시계, 날씨(마지막으로 물어본 지역 또는 기억한 기본 지역),
크몽 현황을 한 화면에 보여 줍니다. 마우스를 움직이거나 키를 누르거나 "용용아" 하고 부르면 원래대로 돌아갑니다.
크몽 현황이 2시간보다 오래됐으면(오전 9시~오후 9시) 조용히 새로 만들어 15분마다 화면에 반영합니다.

## 밖에서 쓰기 (휴대폰 · 맥북 · 사무실)

1. 맥미니·휴대폰·맥북에 [Tailscale](https://tailscale.com/download) 설치 후 같은 계정으로 로그인
2. 맥미니 터미널: `~/dreamer9761/yongyong/remote_setup.sh` → 원격용 아이디·비밀번호를 정하면 `https://맥미니이름.….ts.net` 주소를 알려 줌
3. 휴대폰 크롬(또는 맥북 사파리)에서 그 주소 → 아이디·비밀번호 로그인 → 글자로 대화
   - 안드로이드 크롬 메뉴 ⋮ → **앱 설치 / 홈 화면에 추가** 하면 용용이 아이콘으로 앱처럼 실행
   - 🎤 버튼을 **누른 채로 말하고 떼면** 맥미니가 받아 적고, 대답을 휴대폰에서 소리로 들려줍니다
- 밖에서 한 요청은 집 스피커로 소리 내지 않고 화면 글자로만 대답합니다. 로그인은 30일 유지, 10분에 5번 틀리면 잠깁니다.
- 비밀번호는 해시로만 `data/remote.json` 에 저장. 접속은 Tailscale 에 로그인한 내 기기에서만 가능합니다.

## 설정 바꾸기 (`yongyong/.env` 에 추가)

```bash
export YONGYONG_MIN_RMS=0.006        # 잘 못 알아들으면 낮추고, 잡음에 자꾸 반응하면 높이기

export YONGYONG_VOICE=Yuna           # 목소리
export YONGYONG_FACE=0               # 캐릭터 창 끄기

export YONGYONG_KMONG_POLL=600       # 크몽 새 문의 확인 주기(초, 기본 10분), 0 이면 끔
```
