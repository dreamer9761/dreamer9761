# 🐉 용용이 — 음성 업무 비서

"용용아" 하고 부르면 Studio Display 마이크로 듣고, Claude Code(Claude Pro 로그인)로 생각해서, 화면 속 아기 용 캐릭터가 입을 움직이며 대답합니다.

## 설치 (맥미니 터미널에서 한 줄, 업데이트할 때도 같은 명령)

```bash
curl -fsSL https://raw.githubusercontent.com/dreamer9761/dreamer9761/claude/mac-mini-local-setup-du34lc/yongyong/bootstrap.sh | bash
```

AI(Claude Code), 음성인식(Whisper), 캐릭터까지 한 번에 설치하고 바탕화면에 **용용이** 아이콘을 만듭니다.

설치 스크립트가 맥 사양(칩, 메모리, 마이크)을 읽어서 말로 알려 주고, 메모리에 맞는 음성인식 모델을 골라 설치합니다.

## Claude 로그인 (처음 한 번)

```bash
~/dreamer9761/yongyong/login.sh
```

브라우저에서 Claude Pro 계정으로 승인 → 터미널에 나온 `sk-ant-oat01-…` 토큰을 붙여넣으면 `yongyong/.env` 에 저장됩니다(이 맥에만 저장, git 에 안 올라감).
용용이가 "Not logged in" 또는 "로그인이 필요해요" 라고 하면 이걸 다시 실행하세요.

## 실행

바탕화면의 **용용이** 아이콘을 더블클릭 (또는 `~/dreamer9761/yongyong/run.sh`).
용용이 캐릭터 창이 뜨고 "용용이 준비됐어요" 하고 인사합니다.

| 캐릭터 모습 | 뜻 |
|---|---|
| 둥실둥실, 눈 깜빡 | 대기 중 ("용용아" 기다림) |
| 초록 빛 고리가 퍼짐 | 듣고 있어요 |
| 말풍선 ··· | 생각(작업) 중 |
| 입이 소리에 맞춰 움직임 + 자막 | 말하는 중 |

- 처음 실행할 때 마이크 권한 창이 뜨면 **허용**
- 음성인식 모델 다운로드 때문에 첫 실행은 몇 분 걸려요
- 종료: `Control` + `C`

## 말하는 법

| 이렇게 말하면 | 용용이가 |
|---|---|
| "용용아" | "네" 하고 8초 동안 다음 말을 기다림 |
| "용용아, ○○ 해 줘" | 바로 처리하고 대답 |
| 대답 후 8초 안에 이어서 말하기 | "용용아" 없이도 알아들음 |
| "용용아, 새 대화" | 이전 대화를 잊고 처음부터 |

개발 작업은 `~/projects` 폴더에서 합니다. 고객에게 보내기·삭제·결제처럼 되돌리기 어려운 일은 먼저 물어보도록 `persona.md` 에 적어 뒀어요.

## 크몽 상담창 연결 (사파리)

용용이는 사파리에 띄워 둔 크몽 탭의 글자를 **읽기만** 합니다 (클릭·메시지 전송 안 함).

**처음 한 번 설정**
1. 사파리 → `설정…` (`⌘` + `,`) → **고급** → 맨 아래 "**웹 개발자를 위한 기능 보기**" 체크
2. 사파리 → `설정…` → **개발자** 탭 → "**Apple Events의 JavaScript 허용**" 체크
   (예전 사파리: 메뉴 막대 **개발자용** → "Apple Events의 JavaScript 허용")
3. 테스트: `~/dreamer9761/yongyong/run.sh --kmong`
   → "터미널이 Safari를 제어하려고 합니다" 창이 뜨면 **허용** → 지금 화면을 요약해서 읽어 줌

**사용**
- 용용이가 켜져 있으면 30초마다 크몽 탭을 확인하고, 새 문의가 오면 먼저 "크몽 알림이에요…" 하고 말해 줍니다.
- "용용아, 크몽 확인해 줘" / "용용아, 지금 크몽 손님 누구야?" 하고 물어봐도 돼요.
- 주문자별 기록(연관 계정, 이전 주문, 진행 상황)은 `yongyong/data/customers.md` 에 쌓여서, 다음에 같은 손님이 오면 예전 기록까지 함께 알려 줍니다.

## 설정 바꾸기 (`yongyong/.env` 에 추가)

```bash
export YONGYONG_MIN_RMS=0.006        # 잘 못 알아들으면 낮추고, 잡음에 자꾸 반응하면 높이기
export YONGYONG_WORKDIR=~/projects   # 개발 작업 폴더
export YONGYONG_VOICE=Yuna           # 목소리
export YONGYONG_FACE=0               # 캐릭터 창 끄기
export YONGYONG_KMONG_POLL=30        # 크몽 확인 주기(초), 0 이면 자동 감시 끔
```
